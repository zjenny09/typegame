## 标题

打字练习乐园（Typing Paradise）

## 一句话简介

四款儿童打字练习小游戏：字母关与单词关，从认键到盲打的启蒙起步。

## 详细描述

打字练习乐园是一款为小学低年级孩子设计的打字练习游戏合集，
四个独立小游戏、每款两关（字母 + 单词），词汇覆盖小学三年级英语核心词汇。

**小青蛙过河**：荷叶上有字母或单词，从左到右依次打对，帮小青蛙跳过小河。
不设限时，打错重输，适合零基础熟悉键盘。

**警察抓小偷**：小偷匀速逃跑，打对一个目标警察就追一步。
打得快就能追上，紧张刺激的速度挑战。

**打雪球**：雪球从天上掉下来，越掉越多——看准了打出上面的字把它砸碎！
任一雪球落地就输，考验多目标分配。

**记忆气球**：气球带着字母升上夜空，看几秒后文字就消失——
凭记忆打出来，让它炸成满天烟花。记忆与拼写双重挑战。

**三档难度**：每个游戏都有轻松 / 标准 / 挑战三档难度，
数量、速度各不相同，零基础到熟练都能找到合适的节奏，
每关每档独立记录最佳成绩。

**特点**

- 完全免费，无广告、无内购、离线可玩
- 每关 1 分钟上下，短局设计适合孩子注意力
- 全键盘操作，Esc 随时退出，孩子可独立上手
- 本地记录每关最佳成绩（星级 + 用时），激励反复练习
- 单词覆盖小学三年级英语核心词汇（约 110 词）

## 操作说明

全程键盘即可：

- 主菜单：A / D 或方向键转动选择，回车进入
- 游戏：直接敲键盘 A–Z 输入；Esc 返回上级
- 结算：A / D 选择按钮，回车确认

Windows 版解压后双击 `TypingParadise.exe` 运行；
网页版点击 Run game 直接在浏览器游玩。
